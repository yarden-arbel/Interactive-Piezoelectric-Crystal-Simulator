# Piezoelectric Effect Interactive Simulator

An interactive, web-based educational simulator designed to visualize the microscopic and macroscopic principles of the piezoelectric effect. Built with React and Tailwind CSS, this tool bridges the gap between physical mechanical pressure and atomic-level electrical generation.

## 🚀 Overview
The Piezoelectric Effect Simulator guides users through an intuitive, step-by-step visual journey. It demonstrates how certain materials (like quartz or bone) convert mechanical stress into electrical energy due to their unique, non-centrosymmetric atomic structures.

## 🌟 Key Features
- **Step-by-Step Visualization:** Seamless progression from raw crystal form to atomic displacement and current generation.
- **Micro & Macro Perspectives:** View both the physical distortion of the crystal block and the shifting of internal ion charges (+/-).
- **Interactive UI:** Smooth transitions, clear animations, and a responsive RTL (Right-to-Left) Hebrew interface optimized for educational purposes.
- **Biological Context:** Includes a dedicated deep-dive section on how the piezoelectric effect governs bone remodeling in the human body.

## 🗺️ Simulation Stages
1. **Normal State (מצב רגיל):** Shows the crystal at rest. Atoms are balanced; positive and negative charge centers coincide, resulting in a net-neutral electrical state.
2. **Deformation (גביש מתעוות):** Visualizes external mechanical force (compression) warping the physical shape of the crystal.
3. **Microscopic Zoom (זום למבנה הכימי):** Zooms into the asymmetrical crystal lattice grid before any atomic displacement occurs.
4. **Atomic Displacement (מה בדיוק קורה שם?):** Animates the physical separation of positive and negative ion centers caused by the structural distortion, creating electrical dipoles.
5. **Current Generation (איך הזרם נוצר):** Demonstrates the accumulation of surface charges driving electrons through an external circuit to power a load (e.g., lighting an LED).

## 🦴 Bonus: Piezoelectricity in Human Bones
The simulator features an expandable module explaining **Wolff's Law**. It illustrates how physical activities like running apply mechanical stress to collagen fibers in bones. This stress generates minute piezoelectric currents that signal osteoblasts (bone-building cells) to reinforce bone density exactly where needed.

## 🛠️ Tech Stack
- **Framework:** React
- **Styling:** Tailwind CSS
- **Icons & Motion:** Lucide React / CSS Keyframes


# סימולטור אינטראקטיבי: האפקט הפיאזואלקטרי

למידה חזותית ואינטראקטיבית של עקרונות האפקט הפיאזואלקטרי ברמת המקרו (החומר הפיזי) וברמת המיקרו (המבנה האטומי). הסימולטור נבנה באמצעות React ו-Tailwind CSS, ומנגיש בצורה פשוטה כיצד לחץ מכני הופך לזרם חשמלי.

## 🚀 אודות הפרויקט
הסימולטור לוקח את המשתמש למסע מודרך בן 5 שלבים, ומסביר כיצד חומרים בעלי מבנה גבישי לא-סימטרי (כמו קוורץ או קולגן) מייצרים מתח חשמלי בעת הפעלת כוח פיזי. הכלי מותאם במיוחד למטרות הוראה, הדגמה מדעית ואינטגרציה באתרי למידה.

## 🌟 תכונות מרכזיות
- **הדמיה שלב אחר שלב:** מעבר זורם ומודרך בין מצב מנוחה, עיוות מכני, תנועת אטומים ויצירת זרם.
- **מבט כפול (מיקרו ומקרו):** הצגה של שינוי הצורה החיצוני של הגביש לצד תנועת היונים הפנימית (+/-).
- **ממשק משתמש נגיש:** תמיכה מלאה בעברית (RTL), עיצוב מודרני, כפתורי ניווט נוחים ואנימציות חלשות וברורות.
- **הרחבה ביולוגית:** תיבת מידע ייעודית המסבירה את חשיבות האפקט הפיאזואלקטרי בתוך גוף האדם (בניית עצמות).

## 🗺️ שלבי הסימולציה
1. **גביש במצב רגיל:** הצגת הגביש במצב מנוחה. המטענים החיוביים והשליליים מתלכדים במרכזם, ולכן הגביש נייטרלי מבחינה חשמלית.
2. **גביש מתעוות:** הדמיה ויזואלית של כוח מכני (לחץ) המכווץ ומשנה את הצורה החיצונית של הגביש.
3. **זום למבנה הכימי:** הצצה אל תוך הסריג האטומי הייחודי והלא-סימטרי של החומר הפיאזואלקטרי.
4. **מה בדיוק קורה שם?:** אנימציה של תנועת היונים תחת הלחץ החיצוני. מרכז המטען החיובי נפרד ממרכז המטען השלילי, מה שיוצר דיפולים חשמליים.
5. **איך הזרם נוצר:** חיבור תיאורטי של מוליכים לקצוות הגביש, המראה כיצד הפרדת המטענים יוצרת מתח ומניעה אלקטרונים במעגל חיצוני (למשל, הדלקת נורה).

## 🦴 הרחבה: האפקט הפיאזואלקטרי בעצמות
הסימולטור כולל רכיב נפתח המציג את **חוק וולף (Wolff's Law)**. הרכיב מסביר כיצד פעולות יום-יומיות כמו הליכה או ריצה מפעילות לחץ מכני על סיבי הקולגן שבעצמות שלנו. לחץ זה מייצר זרמים פיאזואלקטריים זעירים, המאותתים לתאים בוני-עצם (אוסטאובלסטים) לחזק את צפיפות העצם בדיוק באזורי העומס.
